# Completed Sessions

A session lands here when its Definition of Done (see `../conventions.md`) is fully met and
its feature branch has merged into `main`. (Before PR #3 merged on 2026-07-29, this pointed at
`claude/cms-matching-v1` instead — see `../conventions.md` for that history.) A session whose
PR is still open belongs in `../in_review/`, not here — see that folder's README. Files are
never edited after the move to `completed/`; if something turns out wrong, author a follow-up
session instead of rewriting history.

`../index.md`'s "Completed (most recent 3)" list is a capped view of the most recent entries
here; older sessions stay in this folder even after they drop off that list.
