## Keeping this current

- **Found a relevant page** (via this table or a fresh search) that isn't listed, or covers more
  ground than its row shows → add or widen the row now, not as a followup.
- **Updated an existing page** as part of closing out → refresh its row's `Session` and
  `Last touched`.
- **Checked a listed page and it's gone, renamed, or clearly superseded** → say so in the row rather
  than deleting the row silently; a missing link is a signal for the next session, same as a stale
  doc would be.
- This file records *awareness*, not obligation — a repo with no centralized docs stays an empty
  table indefinitely, and that's the correct steady state, not a gap to fill.
