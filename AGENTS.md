# Agent Instructions — patient-matching

**Read `docs/LEARNINGS.md` first.** It records concrete bugs already found and fixed against
real data/environments (e.g. FHIR fields that are present-but-`null`, not just absent) — check
it before re-diagnosing something already solved.

**Then read `docs/sessions/conventions.md` in full** if you're picking up or starting a session
from `docs/sessions/index.md` — it's the authoritative process doc for how work in this repo is
scoped, executed, and closed out.

Log new findings in `docs/LEARNINGS.md` as you go, not at the end of a session.
